# 🎤 Voice AI Meeting Assistant

A simple voice-based AI application that allows users to upload meeting audio and receive an automatic transcription and AI-generated summary using OpenAI’s Whisper and GPT models.

This project demonstrates how to build a real-world GenAI system using:
- Speech-to-text
- Large Language Models
- FastAPI
- A browser-based UI

---

## 🚀 Features

- Upload audio files (.mp3 or .wav)
- Converts speech to text using Whisper
- Uses GPT to summarize meeting content
- Displays transcript and summary directly in the browser
- Simple and clean user interface
- Secure API key handling using environment variables

---

## 🛠 Tech Stack

- Python
- FastAPI
- OpenAI Whisper
- OpenAI GPT
- HTML, CSS, JavaScript

---

## 🎯 Example Use Case

Upload a meeting recording and instantly get:
- What was discussed
- Key decisions
- Action items
